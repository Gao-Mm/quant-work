# Commodity Prices & Trading Volume Dashboard

## Project Overview

This project follows the data analytics workflow with the aim of producing an interactive dashboard in Microsoft Power BI.

## Objectives

- Collect data
- Clean and Transform historical Trading Commodities data
- Perform Explanatory Data Analytics
- Produce a clean dataset in CSV format
- Created a dashboard to check commodity price trends and trading volume

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Google Collab
- Microsoft Power BI

## Project Structure

- `data/` – Dataset used for the analysis
- `notebooks/` – Python analysis notebook (Google Collab)
- `data/' - cleaned dataset used for visuals
- `README.md` – Project documentation

## Key Findings

Price Trend:
Generally commodities price increase over time. Platinum and Gold remain higher compared to the rest with gold being the highest since its lowest dip in 2015. Drivers of this rise include the natural recovery that happens after such a price dip,
geopolitical conflicts, us de-dollarization etc. Natural gas, shows a fluctuating trend which is driven by seasonal rises and dips. Its usually high in the winter seasons and summer seasons. Copper remains the lowest priced commodity at any given year
because of its abundance. 

Trading Volume:
Crude oil and natural gas relatively have the highest trading volume in comparison with other commodities. They have similar trading volumes because they are extracted together and traded simultaneously.
Platinum maintains the least trading volume due to its small market size.

Commodity Trading Range:
Average low and high increase over time, with the year 2026 being the highest for both high and low. 

## How to Run the Project

1. Download or clone the repository.
2. Open the Jupyter Notebook or Google Collab file.
3. Upload data file
4. Install the required Python libraries.
5. Delete # on line "#files.download("cleaned_data.csv")" on the cell just before the dashboard picture
6. Run the notebook cells in order.
7. Upload Dataset to Microsoft Power BI to create dashboard.
